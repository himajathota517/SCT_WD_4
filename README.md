# To-Do Web Application

## SkillCraft Technology — Web Development Internship

**Task 04 | To-Do Web Application**

---

## Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship – Task 04**.

The objective of this task is to develop a **basic yet functional To-Do web application** that enables users to efficiently create, organize, update, and manage their tasks.

The application provides users with the ability to add tasks, maintain task lists, mark tasks as completed, edit existing tasks, delete tasks, and assign date and time information to individual tasks.

---

## Task Objective

The primary objective of this project is to build a user-friendly task management application that allows users to:

- Add new tasks.
- Organize tasks in a structured list.
- Mark tasks as completed.
- Edit existing tasks.
- Delete tasks when they are no longer required.
- Set a date and time for tasks.
- Manage tasks through a simple and intuitive interface.

---

## Key Features

### Task Creation

Users can add new tasks with relevant task information.

### Task Management

Tasks are displayed in an organized manner, making it easy to view and manage multiple tasks.

### Task Completion

Users can mark tasks as completed, providing a clear distinction between pending and completed activities.

### Task Editing

Existing tasks can be modified whenever changes are required.

### Task Deletion

Users can remove tasks that are no longer relevant.

### Date & Time

Tasks can be associated with a specific date and time to support better task planning and organization.

### Responsive Interface

The application is designed to provide a usable experience across different screen sizes and devices.
